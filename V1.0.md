# MINIMICAL DROP 1.0

1.0 is the mature internal infrastructure release, not a SaaS expansion.

## Release gate

- Client workspace and upload recovery remain stable under real project use.
- Delivery workflow is complete: review, changes, approval and delivery state.
- Studio control room covers project health, storage, history and duplication.
- Client and project activity is auditable without exposing internal storage identifiers.
- Admin access remains server-side and tokenized client access remains hash-only.
- Private surfaces remain noindex/no-store and protected by production security headers.
- Google Drive remains an invisible storage adapter.
- Transactional email remains optional and does not block core operation.
- Production health, build and runtime checks pass before release.

1.0 does not introduce client accounts, public registration, multi-tenancy, templates, reminders, or collaboration/chat infrastructure.
